# PRISM

### Photovoltaic Recognition through Intelligent Similarity Mechanisms

Behaviour-informed approaches to behind-the-meter photovoltaic disaggregation in low-voltage networks.

**Thomas Hull**
Queen's University Belfast

---

## About PRISM

Behind-the-meter photovoltaic generation can obscure underlying electricity demand in low-voltage measurements.

PRISM investigates whether behavioural similarity and readily available meteorological information can improve the estimation of hidden demand and photovoltaic generation from aggregate net-load measurements.
